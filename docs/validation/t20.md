# T20：稳态 FSI1 分区耦合验收

日期：2026-10-11。结论：**PASS**。本记录完成 M4/T20；下一阶段为 M5 整体耦合，不在本轮实现范围内。

## 离散与运行路径

- 使用同一 Gmsh MSH2 共享几何拆分流体和固体网格，界面 P1 顶点保持相同全局节点号。
- 流体为稳态不可压 Navier–Stokes，P2/P1 Taylor–Hood，`rho=1000 kg/m³`、`mu=1 Pa·s`、平均入口速度 `0.2 m/s`。
- 固体为总拉格朗日 P1 St. Venant–Kirchhoff，`rho=1000 kg/m³`、`nu=0.4`、`E=1.4 MPa`、单位厚度。
- 每次 Dirichlet–Neumann 候选先将结构界面位移调和延拓到流体网格，构造通过质量门槛的 ALE 当前几何，再解流体、积分当前牵引并解固体。界面用缩放 Aitken；候选求解不修改参考网格。
- 阻力/升力为固定圆柱边界力与弹性梁界面力之和。结果保存各层网格、迭代 CSV 和完整场 NPZ。

配置为 [`cases/fsi1.json`](../../cases/fsi1.json)，入口为：

```bash
.venv/bin/python -m fsi_ice fsi1 --config cases/fsi1.json --output results/t20/fsi1
```

## 失败与修正证据

第一次正式三档选择为 `0.04/0.02/0.01 m`。该运行所有守恒和求解残差均通过，最细阻力误差为 0.564%，但 y 位移误差为 5.449%，超过冻结的 5% 门槛，因此报告为 FAIL；没有放宽门槛。新增 `h=0.0075 m` 实际求解后误差降为 4.076%，最终配置改为 `0.02/0.01/0.0075 m` 并重新完整运行得到 PASS。
