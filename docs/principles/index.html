这个项目要做什么

fsi_ice 是一个用 Python 从零实现的流固耦合（FSI）研究平台： 流体、固体、动网格、界面传递和耦合算法全部自研，不调用现成求解器； 只使用 NumPy/SciPy 做数组与线性代数、Matplotlib 画图、pytest 做测试。

目标不是"能算一个例子"，而是公平地比较方法：分区耦合和整体耦合必须求解同一个离散物理问题—— 相同的网格、材料、边界、时间步和物理残差——然后比较精度、稳定性、收敛性和计算成本。 基准采用公开的 Turek–Hron FSI1/FSI2，单场则用 Poisson 制造解、CSM 系列（固体）、CFD 系列（流体）等逐级建立可信度。

阅读提示：本页解释"为什么这样算、每一步做什么、怎么确认可信"，不假设读者学过有限元。 范围、验收门槛与规范以 spec.md 为准，阶段进度以 gola.md 为准， 更细的任务分工见 agent.md。

一次计算会经历什么

把"算一个算例"拆成固定步骤，每步只做一件事，方便单独替换和验证。 以稳态 FSI1（代码 validation/fsi1.py）为例：

  1. 读配置：JSON 写明网格尺寸、材料、边界、时间步与容差（如 cases/fsi1.json）；算例参数不散落在求解器内部。
  2. 双域网格：同一几何拆成流体与固体网格，界面节点一一对应；网格由外部 Gmsh 生成，方程离散和求解全部自研（mesh/turek.py）。
  3. 候选步：给定界面位移 x，先把固体位移调和延拓到流体网格（动网格更新），解流体，把界面载荷传给固体，解固体，得到新的界面位移 G(x)。每一步都从已接受历史出发，不修改参考网格。
  4. 耦合迭代：比较 G(x) 与 x 的残差；不满足容差就按固定松弛或 Aitken 更新 x，再重复候选步（见耦合怎么做）。
  5. 全场事务：一个时间步的网格、流体、固体和时间历史一并准备，全部成功才原子地接受；任何失败整体回滚，重试与冷启动逐位一致。
  6. 报告：保存残差、守恒量、迭代历史、配置与运行环境；是否通过以报告中的 status 和检查项为准，不以"命令能运行"为准。

几个关键概念

1. 一切归结为"残差 = 0"

每个物理模块提供残差 R(状态)（大致是"内部力减外部力"）及其导数（Jacobian，也称切线）。 线性问题里切线不随状态变化；非线性问题用牛顿法反复解 J·Δx = −R。 分区耦合和整体耦合都基于同一套残差，只是把它们组合和求解的方式不同——这保证两种方法的比较是公平的。

2. 候选历史与已接受历史严格分开

时间推进用固定步长 BDF1/BDF2：BDF1 是 (d(n+1)−d(n))/dt， BDF2 是 (1.5·d(n+1)−2·d(n)+0.5·d(n−1))/dt。 耦合迭代会在同一时间步反复求解，所以"候选状态"绝不能写进"已接受历史"； 只有整个时间步成功后才统一接受，失败则完整回滚（time/transaction.py）。 读监测值和重试用数据都以已接受状态为准。

3. 动网格与几何守恒

固体变形会让流体网格跟着动。先用调和方程把界面位移延拓到整个流体网格（ale/harmonic.py）， 得到网格位移 d 与当前坐标 X+d；变形梯度 F = J(x)·J(X)⁻¹， 要求 j = det F > 0（单元不翻转），并设最小体积比和最小单元质量门槛，违规的候选几何被拒绝且不改变参考网格。 ALE 对流项使用相对速度 u−w（w 是网格速度）。 有限时间步下，"位移差分得到的速度"与"使体积收支精确的扫掠通量速度"并不相等， 程序把它们分别命名、分别验证（离散几何守恒：∇(X)·Q_BDF = g_BDF，见 ale/gcl.py）。 "只把对流速度换成 u−w"是不够的——体积收支必须用满足离散 GCL 的扫掠通量。

4. 界面传递必须严格对偶

界面约定：运动映射 H 把固体界面位移插值到流体一侧（当前为 P1 固体 → P2 流体）； 流体牵引 t(s) = −σ(f)·n(f) = σ(f)·n(s) 积分成节点力后，用 Hᵀ 转到固体， 保证离散虚功一致：δdᵀ·f(s) = (H·δd)ᵀ·g(f)。 厚度只计入一次；参考构形只匹配一次，不在变形后重新匹配；几何、力的方向与符号都有测试固定。

各模块怎么做的

每个模块都回答同样的问题：解决什么问题、程序怎么做、怎么确认算得对、当前做到哪一步。

网格与有限元基础（M0）已验证

解决什么问题：把平面区域切成三角形小片，用分片简单函数近似未知量，把微分方程变成代数方程组。 程序怎么做：mesh/triangular.py 存储点、三角形单元（逆时针）和边界标签； fem/p1.py 提供 P1 形函数与梯度；积分用三角形求积表；单元贡献按自由度编号组装成稀疏矩阵； Dirichlet 边界用分块消元处理。 怎么确认：形函数分片单位性与导数和、单项式积分精确性、线性场再现（patch test）、 Poisson 制造解三网格收敛：L2 阶 1.994、H1 半范阶 0.997（门槛 1.8 / 0.9）。 证据：M0 记录；测试 test_mesh.py、test_fem.py、test_poisson.py。

固体求解器（M1）已验证

解决什么问题：计算弹性体在载荷下的位移与应力，从线性小变形扩展到有限变形。 程序怎么做：小变形线弹性 σ = λ·tr(ε)·I + 2μ·ε，可选平面应力/平面应变（solid/linear.py）； 有限变形采用总拉格朗日 St. Venant–Kirchhoff：F = I + ∇d，E = ½(FᵀF − I)， S = λ·tr(E)·I + 2μ·E，P = F·S，配一致切线与牛顿迭代（solid/stvk.py）； 动力学写成 d' = v、M·v' + r(d) = f，用 BDF1/BDF2 推进（solid/dynamics.py）。 非正 det(F) 直接拒绝，不静默继续。 怎么确认：刚体运动零内力、patch test、中心差方向导数（门槛 1e-5）； CSM1/2 静力最细网格 y 位移误差 0.536% / 0.546%； CSM3 动力频率误差 0.481%、振幅误差 2.10%（门槛 5% / 10%）；固体 BDF1/BDF2 时间阶 0.973 / 1.986。 证据：单场记录；测试 test_solid.py、test_stvk_time.py。

流体求解器（M2）已验证

解决什么问题：计算不可压牛顿流体的速度与压力，从 Stokes 扩展到稳态/瞬态 Navier–Stokes。 程序怎么做：速度—压力采用 P2/P1 Taylor–Hood 混合元；物理压力约定 σ = −p·I + 2μ·ε(u)； 方程 ρ(∂u/∂t + (u−w)·∇u) = −∇p + μΔu + f、∇·u = 0（固定网格时 w=0）； 封闭边界固定一个压力自由度，自然出口不固定（fluid/taylor_hood.py）。 瞬态线化系统用 GMRES 加 LU 预条件，并检查真实线性残差而不是只看迭代历史。 怎么确认：Poiseuille 流精确再现；解析 Stokes/Navier–Stokes 空间收敛速度阶 3.02、压力阶 2.13（门槛 2.7 / 1.8）； CFD1/2 稳态阻力相对误差 0.482% / 0.623%，升力 0.629% / 1.394%； CFD3 动态频率误差 0.488%、升力振幅误差 0.378%、阻力均值误差 0.874%（门槛 10%）；流体 BDF1/BDF2 时间阶 0.986 / 2.030。 证据：单场记录；测试 test_fluid.py、test_transient.py。

动网格 ALE（M3）已验证

解决什么问题：让流体网格随固体运动而不翻转，并保证移动网格上的质量守恒。 程序怎么做：调和延拓（每个分量解一次 Poisson）给出网格位移（ale/harmonic.py）； ale/geometry.py 建立候选几何并做质量门槛检查（默认最小体积比 0.2、最小质量 0.1）； 网格速度由 BDF 位移求导、P2 取端点平均（ale/kinematics.py）； ale/gcl.py 构造满足离散 GCL 的扫掠通量； fluid/ale.py 提供带 ALE 上下文的残差与网格方向导数（JVP）。 怎么确认：仿射/常数场精确再现（≤4.4e-16）；调和解收敛 L2/H1 阶 1.98 / 0.99； 固定网格退化与既有实现逐位一致（≤5.6e-17）；GCL 逐单元缺陷 ≤3.0e-16； ALE 制造解空间阶 3.06/3.09，时间阶 BDF1 0.91–0.95、BDF2 2.01–2.17；JVP 与中心差分对比 1.6e-12（门槛 1e-5）。 证据：M3 矩阵（14-01…15-06）；测试 test_ale_mesh.py、test_ale_fluid.py。

界面传递（M3）已验证

解决什么问题：在固体和流体之间同步传递运动（位移/速度）与力（牵引/节点力），且不发生能量凭空产生。 程序怎么做：interface/topology.py 建立匹配界面并固定自由度对应关系； interface/mapping.py 实现运动映射 H 与对偶载荷 Hᵀ； interface/traction.py 从流体解积分 Cauchy 牵引，含 Nanson 参考/当前构形转换与厚度一次计入； 还提供载荷对速度、压力、网格和固体位移的方向导数（供整体耦合 Jacobian 使用）。 怎么确认：恒等式（H·1=1、P2 迹=端点平均、n(s)+n(f)=0）误差 0～3.6e-15； 虚功一致性 1.3e-15；矩平移检查；载荷方向导数 2.7e-15～3.4e-11（门槛 1e-5）。 证据：M3 矩阵（16-01…16-DER）；测试 test_interface.py。

时间推进与全场事务（M3）已验证

解决什么问题：管理 BDF 历史与整个时间步的候选/接受/回滚，保证失败重试与"从未出错"的基线一致。 程序怎么做：time/bdf.py 提供只读 BDF 模板与历史； time/transaction.py 实现两步事务：先在私有副本上完成所有可能失败的操作（prepare）， 全部成功后才一次性替换（publish）；任何失败都不留部分状态。 怎么确认：故障注入覆盖几何翻转、固体牛顿失败、流体奇异矩阵、末端校验失败、序列化失败、 重复评估、连续失败后重试等 10 类场景；失败后所有场与历史的数组逐位不变；加域重试与冷启动逐位一致。 证据：M3 矩阵（17-01…17-RETRY，61 项事务测试）；测试 test_transaction.py。

耦合怎么做

分区耦合（已完成，M4）。最直觉的 FSI 做法是"流体和固体轮流解"： 给一个界面位移 x，解流体得到载荷，传给固体，解固体得到新的界面位移 G(x)； x 几乎不变时说明两边都满意了。这就是 Dirichlet–Neumann 迭代。 为了稳定，更新时加松弛： 

x(k+1) = x(k) + ω·( G(x(k)) − x(k) )
  • 固定松弛：ω 取常数（默认 0.5），简单但可能需要很多次迭代。
  • Aitken 自适应：根据上一步残差自动调整 ω，公式为 ω(k) = −ω(k−1)·(r(k−1)·(r(k)−r(k−1))) / ||r(k)−r(k−1)||²， 并限制在 [0.05, 1] 内；分母退化时保留上一步系数并记录原因。

收敛判据是未松弛的界面残差按显式物理尺度归一化后小于容差： ||G(x)−x||/scales ≤ atol + rtol·max(||x||/scales, ||G(x)||/scales)。 尺度必须由调用者显式给出，避免不同单位的量直接比较；收敛的结果保留"最后评估的输入与对应单场状态"， 不把 x 静默替换成 G(x)。失败（不收敛、单场抛错）返回带完整历史的终止异常，绝不返回假成功。

怎么确认：先用一个小型真实有限元问题（固定参考几何、BDF1 一步） 把分区迭代的解与"同一离散方程的块直接解"比较：位移差 3.41e-13、速度差 6.76e-12、压力差 4.16e-12（门槛 1e-8）； 同一问题固定松弛需 27 次评估，Aitken 用 7 次（仅作记录，不作为普遍加速承诺）。 然后在正式 FSI1 稳态基准上验收：

整体耦合：所有场放进同一个方程组（M5）已验证

要解决什么问题。分区耦合把流体和固体分开轮流解，在外层反复迭代界面条件； 当两边耦合很强时，外层迭代可能很慢甚至不收敛。整体耦合换一个做法： 把流体、固体、动网格和界面力的全部未知量放进同一个非线性方程组， 用牛顿法让所有方程同时成立，不需要外层耦合迭代。 它与分区耦合使用同一套网格、材料、边界、时间离散和物理残差，只是组合与求解方式不同； 在相同离散下公平比较两种方法，正是本项目要回答的问题（spec.md §3.3、§5.3）。

过程。整体法把一次求值写成一个纯函数 x ↦ R(x)：给候选状态 x，算出"方程还差多少"的残差向量 R； 牛顿法再反复解线性方程 J·Δx = −R 修正 x（J 是 R 对 x 的导数）。 求值入口在 coupling/monolithic.py， 牛顿迭代与定常推进在 coupling/monolithic_newton.py、 coupling/newton.py。 下面依次说明未知量、残差、Jacobian、方向导数验证、Newton 与定常推进。

未知量 x 的六个块

x 按固定顺序分块，二维节点量按"节点优先、x/y 交错"存放；各块切片与形状由 BlockLayout 记录并校验：

块含义离散 / 说明
u_f流体速度P2（Taylor–Hood），形状 (n_P2, 2)
p_f流体压力P1，形状 (n_P1,)
d_s / v_s固体位移 / 速度（参考构形）P1 总拉格朗日 StVK，各 (n_s, 2)
d_m流体参考网格位移；候选几何为 X + d_mP1，形状 (n_f1, 2)

六行残差分别表示什么

把同一个 x 代入六个方程就得到六行残差。每一行都复用单场物理核（不重写一套物理公式），只是接受来自其他块的输入：

  • 流体动量与连续性 R_u、R_p：在 d_m 给出的候选几何上调用 ALE Navier–Stokes 残差核（含 GCL 扫掠通量与相对速度对流）。 已知速度的边界行改写为 u_f − u_D；湿界面上的流体 P2 迹行改写为界面运动连续条件 G_f u_f − H G_s v_s，即流体界面速度必须等于固体界面速度经映射 H 后的值。
  • 固体运动学 R_sd：D_BDF d_s − v_s = 0。 BDF 差分算子 D 把当前位移与已接受历史组合成时间导数，这一行表示"速度就是位移的时间导数"。
  • 固体动量 R_sv：M_s D_BDF v_s + f_int(d_s) − f_body − Hᵀ g = 0， 即惯性 + 内力 − 体力 − 界面力；Hᵀ g 把流体给的界面力对偶地转到固体节点上，保证离散虚功一致。
  • 网格约束 R_m：自由行是调和方程 K_h d_m = 0（复用调和延拓的刚度矩阵）； 湿顶点行直接写 d_m|Γ = d_s|Γ（参考构形一一匹配）；其他外边界行取规定值。 这样网格既跟着固体动，又不会翻转或与固体脱开。
  • 界面载荷一致性 R_g：g − g_f_gamma(u_f, p_f, d_m, d_s) = 0； 界面力未知量必须等于用当前解在候选界面几何上积出的流体牵引力（含 Nanson 参考/当前构形转换），否则两侧受力对不上。

约束行与压力规范。已知值（Dirichlet）和耦合约束用"行替换"改写成单位行或约束方程本身，已知值留在残差里； 压力可用可选的 pin 行 p_i − p_ref 固定一个参考值（PressurePin，None 合法）。 FSI1 一致性比较两侧都用 pressure_pin=None（出口自然边界定压，见 m5_freeze.md M-3）。 R(x) 是 x 的纯函数：不修改输入、历史与参考网格，相同输入重复求值逐位一致。

完整耦合 Jacobian：每条依赖链只计一次

牛顿法需要 J = ∂R/∂x。按"行块 × 列块"写出，它是一个分块矩阵；0 表示该行在物理上不依赖该块。 表中 I 是单位块，a₀ 是 BDF 时间系数：

行块 \ 列块u_fp_fd_sv_sd_mg
R_uJ_uuJ_up00J_um0
R_pJ_pu000J_pm0
R_sd00a₀I−I00
R_sv00K_sa₀M_s0−Hᵀ
R_m00J_m_ds0K_h0
R_g−L_u−L_p−L_ds0−L_dmI

耦合来自两条链，分别由两个方向导数（JVP）核覆盖，互不重复：

  • 几何链（ale_geometry_jvp）：固体位移经网格约束影响 d_m，d_m 改变候选几何、GCL 扫掠通量、历史质量、对流与网格输运； 这些"对流体的影响"一次算清，构成 J_um/J_pm 与网格行的 J_m_ds。
  • 载荷链（interface_load_jvp）：界面牵引积分对速度（L_u）、压力（L_p）、网格位移（L_dm）、固体位移（L_ds）的导数， 构成 R_g 行的非对角块；R_sv 行再通过 Hᵀ 使用 g。

怎么证明没有漏项。把任一耦合矩形块从 J 中删掉再与中心差分对照：全项误差在 1e-10 量级， 删掉一个块后会跳到 1e-4–1e-2 量级，说明该块确实被方程使用。T21 对 8 个耦合矩形块做了这种"删块完整性审计"； 每个块的导数来源记录在 JACOBIAN_BLOCK_SOURCES 中。唯一的近似是"可调用体力"在几何方向导数里用固定步长中心差分 （BODY_FORCE_DIFFERENCE_STEP），已单独用中心差分对照，其余全部解析。

怎么确认方向导数算得对

做法是中心差分：在状态 x 上取一个方向 q，对步长 h 计算数值差商 (R(x+hq) − R(x−hq)) / (2h)， 再与解析的 J·q 比较。h 太大时截断误差占主导，太小时舍入误差占主导，所以对 h 从 1e-2 扫到 1e-10，观察相对误差"先降后升"； 按 spec.md §5.2 事先冻结的门槛，取全扫描中的最佳相对误差 ≤ 1e-5。 不同行残差单位不同（力、质量收支、位移等），比较前用逐块显式物理尺度归一化（如长度 1 m、速度 0.05 m/s、压力 0.01 Pa、力 0.01 N）。

实测（小问题、真实有限元离散）：六块混合方向最佳相对误差 7.39e-11（h=1e-6）； 三类独立自选方向（光滑、随机、含界面链）最佳 2.30e-11–5.56e-11； 装配 Jacobian 与矩阵自由 JVP 的相对差 ≤1.9e-16；本应为零的响应方向绝对误差为 0； H、Hᵀ、BDF 相容行、厚度只计一次等恒等式独立抽查误差在 0–2.8e-17 量级。 证据：T21 记录、T21 独立复核； 工具与测试：validation/monolithic.py、 test_monolithic_residual.py、 test_monolithic_review.py。

整体 Newton：阻尼线搜索与收敛判据

每个 Newton 迭代解一次线性系统 J·Δx = −R，再沿 Δx 试探新点。 试探从完整步长 α=1 开始；只有新残差的原始二范数满足 Armijo 充分下降（slope=1e-4）才接受， 否则把 α 减半重试（最多 30 次回溯、不低于 2⁻²⁴）。这条阻尼/回溯线搜索让远处的初值也能稳定靠近解。

判断是否收敛用逐分量尺度归一化的无穷范数：max_i |R_i|/S_i ≤ atol + rtol·‖R0‖_S， S 由调用者按块显式给出，R0 是迭代起点的残差。线搜索用原始残差范数判断下降（避免各块尺度相差悬殊时误拒全步长）， 收敛才用归一化判据——两者分工不同，代码内有注释与回归测试。 T22 小问题（264 个未知量）用 rtol=1e-8、atol=1e-10，4 次迭代后 ‖R‖_S=9.17e-10（阈值 4.66e-5），尾部呈二次收敛趋势。

失败必须响亮。不收敛、回溯失败、线性系统奇异、NaN/Inf 都会抛出带 phase（residual/evaluate/linear_solve/line_search/convergence）、 iteration、残差范数与诊断映射的 MonolithicNewtonFailure，并保留已完成步的计数与记录； T22 注入的六类失败都按预期抛出，失败后基础状态逐位不变，撤销注入后重解与基线一致。被拒绝的试探点只付残差评估成本，切线只在接受的迭代点组装。

两条切线路由，不静默切换。jacobian_mode="assembled"（默认）在接受的迭代点组装 J 并用直接分解（splu）求解； "jvp" 用矩阵自由算子，每次 GMRES 内迭代只乘一次方向导数。路由、线性求解器与各自计数都写进结果； 切线不可用或线性求解失败直接报错，绝不自动换算法。jvp 路由已用小问题加"精确预条件"验证接线与计数， 但无预条件 GMRES 在 264 个未知量上已不收敛——让 Krylov 路径可用于真实问题需要预条件，这是当前的计划项。

从瞬态推进到定常：伪时间 BDF

整体残差用的是时间步格式：BDF 用当前步与已接受历史算时间导数 D_BDF x = a₀x + Σ_{j≥1} a_j x^(k−j)（系数由 dt 与阶次决定，见 time/bdf.py）。 定常（稳态）意味着状态不再随时间变化：固定点上 BDF 模板系数满足 Σa_j = 0，时间项精确抵消， 步残差就退化为稳态离散方程。于是不必另写一个稳态求解器： 用伪时间 BDF 一步步向前走，每步 Newton 收敛后接受为新历史，直到状态不再变化，固定点就是稳态离散解。

停机判据与成本。停机看"尺度化时间项" T_b = max_i |a₀x_i + Σ a_j x_i^(k−j)| / S_i， 只对含时间导数的三块（u_f、d_s、v_s）取最大，当 max_b T_b ≤ steady_tolerance 时判定到达稳态； 跑满步数则如实返回"未到稳态"，不假装成功。 T22 小问题用 dt=0.5 与 0.25 两轮都推进到稳态（末步时间项 6.3e-12 / 2.0e-11），两个 dt 的固定点逐块差最大 2.1e-9（压力块），其余 ≤1.8e-10、位移类约 1e-14； 固定点处步残差与自一致稳态残差逐位相同，再从行进解解一步需要 0 次 Newton。 T23 在真实 FSI1 网格（h=0.02）从零态推进：1e-10 档 8 步、8 次 Newton、约 178 s 达到固定点。 成本口径记录伪时间步数、Newton 次数、组装/线性求解耗时与时间项收敛值（见 T23 记录 §8），便于与分区法对照。

证据：T18 计划、T18 记录、 T19 Aitken 验收、FSI1 计划、T20 验收； 代码 coupling/partitioned.py； 测试 test_partitioned.py、test_aitken.py、test_fsi1.py。

怎么判断算得对

本项目不靠"图看着对"或"程序没报错"判定正确性，而靠事先写好门槛的可重复数值证据：

  • 门槛先于实现：误差、守恒与收敛门槛写在算例配置和 spec.md 中，不允许为让失败的测试通过而临时放宽。
  • 构造已知答案：patch test（精确复现线性场）、制造解 MMS（已知解析解 + 预期收敛阶）、Poiseuille 流等解析算例。
  • 导数与残差一致：解析切线/JVP 与中心差分对照，误差趋势随扰动减小而下降；报告真实残差，不用求解器内部数字代替。
  • 守恒与对偶：质量收支、几何守恒（GCL）、界面虚功/功率、总力与总矩、作用力反作用力。
  • 与公开参考比较：CSM/CFD/FSI1 数值对照 Turek–Hron 基准与 FeatFlow 官方结果，使用核验过的来源与单位。
  • 重复性与失败注入：重复运行逐位一致；人为制造失败验证回滚与重试等价于冷启动；失败不保留旧 PASS。
  • 完整回归：每次功能改动后在项目 .venv 本地运行全部测试（M5 冻结状态为 557 项通过、2 项跳过；本页维护不重跑数值测试），相关领域另跑专项回归。

每项功能的验证日期、命令、环境、参数、预期标准、实测结果与结论记录在 docs/validation/ 下的专门文档中；机器可读的门槛见 cases/。 未实测的功能保持"计划"状态——存在测试文件不等于测试已通过。
