# M6 后处理与收敛研究准备

日期：2026-10-12。单一执行者实现与自查；不提交、不推送。当前 IQN 20 s 算例继续运行，包内 `src/fsi_ice` 源码与运行配置冻结。

## 本轮交付

1. 独立只读脚本从完整断点一次性读取已接受账本，校验断点，再复用现有 `analyze_fsi2`。生成 JSON、Markdown、周期统计 CSV、真实时程图及周期窗口图，不读取正在逐行改写的 monitor.csv，不修改任何求解输出。
2. 区分目标时长完成、每步物理门控、周期稳定及参考精度。未到目标即 INCOMPLETE；未稳定的周期量只作暂定统计，图上标清截止时间。失败目录可分析已接受前缀，但不得变成 PASS。
3. 生成 T26 三网格／三步长配置与四算法重复计时清单，只生成文件和可复现命令，不启动额外长时求解。各组固定另一离散变量；从静止独立运行，不借用不同配置的断点。

## 预先冻结的研究矩阵

- 空间组：IQN，h=0.02/0.01/0.005 m，dt=0.0025 s，BDF2，20 s。
- 时间组：IQN，h=0.005 m，dt=0.01/0.005/0.0025 s，BDF2，20 s。最细交点复用，不重复计算。
- 当前 h=0.02、dt=0.01 仅为已有基线，不冒充上述独立收敛组成员。
- 算法成本：候选 h=0.005、dt=0.0025，fixed/Aitken/IQN/monolithic，各3次独立重复；必须先确认该共同配置的周期与收敛证据，再执行和形成排名。记录硬件、环境、线程、全程墙钟与监测中的求解/线性/耦合计数。并发运行的耗时只能用于诊断。
- 每条时程沿用现有物理、周期与基准门槛。独立收敛研究要求三个已完成且稳定的结果；报告逐档参考误差及相邻差值。最细两档的振幅、频率、阻力均值之差各不超过对应参考尺度的2%，细化差值应递减；最细档还须通过既有基准门槛。没有这组证据不宣称收敛或M6完成；若20 s未稳定，显式延长组内各算例到共同终止时间。

这些离散值为候选研究配置，计算成本尚未实测；准备清单不等于完成研究。空间/时间交点既可减少重复计算，也避免用粗网格误差掩盖时间误差。

## 实际验证要求

后处理以已知正弦信号校验周期、振幅、时均值、参考误差；覆盖短程、未稳定、精度FAIL、失败前缀、物理门控异常、损坏断点和输出路径保护。真实断点后处理前后输入摘要必须相同。研究生成器核验配置、组内单变量变化、交点复用、算法重复次数及绝不启动求解器。修改原理文档并检查结构、本地链接、宽窄屏布局。证据记在 `docs/validation/m6_postprocess.md`。
