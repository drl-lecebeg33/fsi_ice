## 尺度与门槛约定

尺度约定沿用 [m3.md](m3.md)：`eps=np.finfo(float).eps`；数组误差默认 `max(abs(a-b))/S`，`S` 为对应显式正物理尺度与相关贡献和的较大者。FSI1 比较的显式尺度拟为 `L*=0.41 m`（通道高）、`U*=0.2 m/s`（平均入口速度）、`P*=max(rho*U*^2, mu*U*/L*)=40 Pa`、`F*=14.29426 N/m`（参考阻力）；执行前由 A0 冻结，同一比较中全表一致。

逐变量一致性判据（来源：spec §5.2“FSI1 两种耦合方法：收紧求解容差后得到一致离散解；采用逐变量尺度和明确的绝对/相对容差”）：

```text
max|a_M - a_P| <= rtol * max(||a_M||inf, ||a_P||inf) + atol
rtol = 1e-8（拟议）；atol = 1e-10 * S*（按变量，拟议）
```

`rtol` 与 `atol` 是拟议值（依据：终止容差收紧到 1e-10 后差异主要来自终止准则与舍入；比较容差比其宽两个数量级），**不是** spec 固定门槛，执行前由 A0 冻结；任何调整须记录理由，且不得放宽 spec 固定门槛（方向导数 ≤1e-5、FSI1 相对误差 ≤5%、tip_x 绝对 ≤1e-5 m、lift 绝对 ≤0.1 N/m）。依赖拟议门槛的条目（22-xx、23-xx）在门槛冻结前状态不得改为 `passed`；21-01…21-05 的门槛为 spec 固定值或既有冻结裁决，已在 r1 独立验证后更新为 `passed`。

阈值来源分三类，表中逐项标注：（a）**spec 固定值**：直接来自 [spec.md](../../spec.md) §5.2（21-02/21-03/21-05 的方向导数 ≤1e-5、23-08 的 FSI1 误差行）；（b）**既有 A0 冻结裁决**：沿用 [m3_freeze.md](../development/m3_freeze.md) §6.1（22-03 重试-基线 ≤1e-10、21-01/21-05 代数恒等 ≤1e-12·S），不新增更宽的值；（c）**拟议值**：T23 逐变量容差、收紧序列与成本口径，依据 spec §5.2“逐变量尺度和明确的绝对/相对容差”与 §5.3 要求给出，执行前冻结。三类均不得与 spec 相冲突。

## 证据更新规则

1. 只有 A0/A7 在本地实际运行并复核后，才能把本矩阵状态从 `not_executed` 改为 `passed` 或 `failed`，并把证据指向真实报告路径；不得用计划、设计文档或配置文件替代证据。
2. 失败必须如实记录并分析原因；门槛冻结后不得为通过而放宽（见 [m3_freeze.md](../development/m3_freeze.md) §6、[spec.md](../../spec.md) §5.2）。
3. 每项证据至少记录：命令与退出码、配置/代码状态指纹、Python/依赖版本与线程/硬件、mesh/cell/DOF、变量尺度与容差、实测残差/误差/迭代计数/耗时、失败计数。
4. 一致性比较必须使用收紧到平台的同一档结果；成本数字必须来自 §4.2 计时口径下的同次运行。
5. `cases/m5_validation.json` 中每个条目的 `id` 与本文件表格编号一致；`status` 同步维护为 `not_executed`/`passed`/`failed`。M5 完成状态由 A0 在收到全部证据后统一更新到 [gola.md](../../gola.md) 与 [agent.md](../../agent.md)。
