## 2. 实现要点

**复用（不复制物理）**：`ale_navier_stokes_residual`（R_u/R_p 与 J_uu/J_up/J_pu）、`build_ale_geometry`/`build_gcl_transport`/`build_ale_flow_context`（候选几何与 ALE 上下文）、`ale_geometry_jvp`（J_um/J_pm）、`stvk_residual`/`assemble_mass`/`assemble_elasticity`（R_sd/R_sv 与切线、体力载荷）、`HarmonicExtension.stiffness`（R_m 的自由行，按 `kron(K_h, I_2)` 作用于两个分量，与调和延拓的逐分量求解完全一致）、`assemble_interface_load`/`interface_load_jvp`（R_g 与 L_u/L_p/L_ds/L_dm）、`topology.H`/`solid_dofs`（H 与 Hᵀ）。

**残差与行替换**：未消元残差按契约 §2 组装；随后替换约束行——非湿壁已知速度行 `u_f - u_D`、湿流体 P2 迹行 `G_f u_f - H G_s v_s`、压力 pin 行 `p_i - p_ref`、固体 Dirichlet 行、网格湿顶点行 `G_m d_m - H_d G_s d_s`（`H_d = I`，一一匹配）、网格其他外边界行 `d_m - d_m,D`。约束行的 Jacobian 为对应约束方程的导数（Dirichlet/pin 为单位行，湿界面行为 `1` 与 `-H`/`-I` 项）。

## 7. 失败与修正

1. **批量几何列（首次实现）**：按“节点着色 + 逐节点行支撑提取”合批时，同色节点虽不共享单元，但其关联单元的 P2/压力自由度会经共享边/顶点重叠，且同一节点的多个关联单元会让同一行自由度在列中重复出现，COO 求和因此重复累加该自由度的贡献（实测最大列偏差 0.13）。修正：改用“关联单元顶点集合相交”冲突图着色，并对每个节点的行自由度取唯一集合。修正后与逐自由度直接路径对照为逐位相同（最大差 0.0）。
2. **矩阵自由 JVP 的湿界面行**：初版对 `u_f,Γ - H v_s,Γ` 误用 `q_d_s` 而非 `q_v_s`，`J@q` 与 JVP 相对差 2.2e-2。修正后为 1.6e-16。
3. **网格块向量拉普拉斯**：初版直接以标量 `K_h` 乘 `d_m`，维度不符（`(n,n)` 对 `(2n,)`）。修正为 `kron(K_h, I_2)`，与 `HarmonicExtension.extend` 的逐分量求解一致。
4. **测试自身**：`make_direction` 初版在仅给 `d_m` 时用零 `d_s` 覆盖界面迹，导致“仅湿界面 `d_m`”方向退化为零；stale 用例初版 generation 恰好相等。两处均已修正并复跑。
5. **M-4（协调者交叉复核提示，已修正）**：`MonolithicEvaluation.timings['total_seconds']` 初版误用“最后阶段起点”，使 residual/JVP 模式的 `total_seconds` 只反映最后一个子步骤（实测残差模式为 2.4e-4 s）。修正：在求值入口记录总起点，`total_seconds` 改为整次求值累计；`fsi1_smoke.json` 的 `mode_seconds`/`timings` 已用修正后的代码重跑（残差 0.27 s、JVP 0.69 s、组装 Jacobian 19.43 s）。该修正只影响计时字段，不影响任何残差/Jacobian 数值；其余冻结补充（`pressure_pin` 可选、无需稳态模式、`block_norms` 仅作监视量、残差与 Jacobian 只读输出稳定）与本实现一致，分别由 pin=None 用例与不变性/只读输出测试覆盖。
6. 无放宽门槛的调整；`1e-5` 与 `1e-12·S` 沿用既有冻结值。

## 8. 结论与未决问题

**结论（T21 范围，已验证）**：整体残差复用全部单场核并在同状态下逐项一致；完整耦合 Jacobian（含界面与网格几何依赖）与矩阵自由 JVP 在装配与逐列两条路径上一致；每块与全局方向导数最佳相对误差 1e-10 量级（门槛 1e-5）且展示截断→舍入趋势；几何/载荷链式项各计一次；厚度只计一次、压力规范与约束行按契约；不变性、重复性、只读输出与全部拒绝条件均有实测证据。

**未决问题（交下游）**：
