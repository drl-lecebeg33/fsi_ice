## 实现要点

`src/fsi_ice/coupling/partitioned.py` 在 T18/T19 既有接口上扩展 IQN-ILS：

- `CouplingOptions.method` 接受 `'iqn'`；新增字段 `iqn_initial_relaxation`（ω_0，默认 1.0）、`iqn_alpha_max`（默认 10）、`iqn_history_size`（默认 0，无界但受 `max_iterations-1` 上限）、`iqn_restart_tolerance`（默认 1e-2）。
- `solve_dirichlet_neumann` 在每个评估后维护 `(s_j, y_j)` 历史；第 k 步构建 V_k = [s_j + ω_0·y_j]，解 V_k α = −r_k（最小二乘），更新 x_{k+1} = x_k − V_k α。
- 重启条件：LS 报告的数值秩小于历史列数、α 任一分量 |α|∞ 超过 `iqn_alpha_max`、相对 LS 残差超过 `iqn_restart_tolerance`。重启清空历史并回退到 ω_0·r_k 步。
- `CouplingIteration.relaxation_reason` 取值新增 `iqn_initial` / `iqn` / `iqn_restart`，与既有 `fixed` / `aitken` / `initial` / `denominator_degenerate` / `clipped` / `aitken` / `converged` / `max_iterations` / `coefficient_nonfinite` 兼容。

`src/fsi_ice/validation/partitioned.py` 的 `validate_config` 接受上述 4 个新字段为 `coupling` 的可选项；`iqn_history_size` 必须为非负整数，其他字段沿用既有标量校验。`cases/iqn_check.json` 提供默认冻结配置（ω_0=0.5，α_max=10，历史长度 10，相对重启容差 1e-2）。CLI `partitioned-check --method iqn` 已生效。`src/fsi_ice/coupling/transient.py` 的 `TransientFSI.step` 仍只接受 `fixed`/`aitken`/`monolithic`，不引入新公共字段。
