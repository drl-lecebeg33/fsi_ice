日期：2026-10-13。12秒续算在1200步成功结束，全场物理门槛通过，但原周期统计的三个均值波动约2.2%–2.3%，略超原2%门槛。只读诊断发现，同一周期的频率使用二次插值峰时刻，均值却在整数采样峰时刻之间积分，实际窗口交替包含45/46个时间步。
