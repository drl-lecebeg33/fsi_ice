## 2. 实现要点

### 2.1 适配层与显式切线路由

`solve_monolithic_step(context, x0, *, options, scales, jacobian_mode, ...)` 把 `MonolithicContext` 与候选 `x0` 绑定为 `solve_newton` 的纯评估器：

- **线搜索试探用 `mode="residual"`**（M-5 冻结口径）：试探评估对象只读 `residual`；`jacobian=None` 属正常，不触发任何报错或补算。
- **接受点惰性切线**：`solve_newton` 读取评估对象的 `jacobian` 时才补算——
  - `jacobian_mode="assembled"`（默认）：对同一 `x` 追加一次 `mode="assembled"` 评估，直接法 `splu`；被拒试探只付残差费用；
  - `jacobian_mode="jvp"`（大规模预留）：返回矩阵自由 `LinearOperator`，`matvec(q)` 调用一次 `mode="jvp"`（T21 `_jvp_single`，含残差+几何重建），线性求解用 GMRES；可选 `preconditioner=f(x) -> operator` 作为 `M` 显式传入。
- **不允许静默回退**：路由是显式配置并记录在结果（`jacobian_mode`、`linear_solver`）与计数（`assembled_evaluations`/`jvp_evaluations`）中；切线不可用或线性求解失败直接抛出结构化异常，绝不改换算法。`preconditioner` 只在 `jvp` 路由合法（否则 `ValueError`）。

### 2.2 界面相容性（T21 定义域）

T21 残差要求 `d_m|Γ = H_d d_s|Γ`（P1 一一匹配，`H_d = I`），且候选界面几何带缝隙检查（`atol + rtol·scale`）。约束行是线性的，Newton 试探 `x0+αd` 在 `x0` 可行时对任意 `α` 保持可行（约束行残差恒为 `(1−α)·R_c(x0)=0`），因此：

- `compatibility="require"`（默认）：求解前检查尺度无关的缝隙 `max|d_m|Γ−d_s|Γ|`，超过与界面几何同形的容差即抛结构化失败（`phase="residual"`，给出 `requirement`、`interface_gap`、`gap_tolerance`）；
- `compatibility="project"`（显式配置）：先用 `project_interface_compatibility` 把网格迹投影到固体迹一次，结果记录 `compatibility_gap`（投影前缝隙）；
- 失败与结果都记录接受点的 `interface_gap`；小问题全程实测 ≤1e-12（多数为 0）。

### 2.3 定常推进与停机判据（定义）

`march_to_steady(context, x0, *, dt, order=2, max_steps=50, steady_tolerance=1e-8, ...)`：

- 初始接受态取模板 `context.base` 的最新一层；`BDFHistory` 重建（generation 从 0 起），`order=2` 按 [bdf.py](../../src/fsi_ice/time/bdf.py) 的 BDF1 启动；每步用当前 history 构造新的 `MonolithicContext`（`step_id`/`generation` 每接受一步 +1，`candidate_id=(模板 id,"march",步号)`），Newton 收敛后接受为新 history，并用收敛的 `d_m` 重建接受几何；模板上下文与输入数组不被修改。
- **停机判据（尺度化 BDF 时间项）**：对状态块 `b ∈ {u_f, d_s, v_s}`（整体残差中仅这三块含时间导数），

  `T_b = max_i |a_0 x_i + Σ_{j≥1} a_j x_i^{(k−j)}| / S_{b,i}`，判据 `max_b T_b ≤ steady_tolerance`；

  `a_j` 为当前步 BDF 模板系数（已除 `dt`），`x^{(k−j)}` 为 latest-first 接受历史。BDF1 时该项恰为 `a_0|x^k−x^{k−1}|`；BDF2 在最近两层相等时化为同一表达式；固定点处 `Σa_j=0` 精确抵消，步残差即稳态离散方程。`steady_tolerance` 无量纲（除以逐块物理尺度，数值单位为 1/s，即相对状态变化率）。
- 终止：`reason="steady"`（判据满足，`steady_reached=True`）或 `reason="max_steps"`（跑满步数，`steady_reached=False`）；两者都返回完整逐 step 记录、聚合计数与计时。Newton 失败按步包装传播（`step_index`、已完成 `march_steps`、聚合计数/计时、含失败步的部分计数）。
- 未修改 `time/transaction.py` 或任何公共文件；事务衔接（StepPlan 整体阶段、stage/field 命名）保留给 A0/A7（§10）。

### 2.4 计数与计时口径（对齐 T23 §4.1）

`MonolithicCounters`（冻结 dataclass，`as_dict()` 可导出）字段：`steps`、`newton_iterations`、`evaluations`（= `residual_evaluations+assembled_evaluations+jvp_evaluations`，含接受点的一次诊断残差评估；另有 `jvp_directions`、`jacobian_reads` 细分）、`linear_solves`、`linear_iterations`、`line_search_trials`、`failed_trials`、`failed_steps`。`linear_iterations` 在 assembled 路由为 0（直接分解无 Krylov 迭代，结果中 `linear_solver="splu"` 标注），在 jvp 路由为 GMRES 内迭代数（`linear_solver="gmres"`）。计时桶 `evaluate_seconds`（每次 T21 求值内部，含组装/物理/残差/JVP；对应 T23 的 `assembly_seconds` 口径）、`linear_seconds`（`splu`/GMRES；矩阵自由 matvec 同时计入 evaluate 与 linear，按文档口径允许重叠）、`newton_seconds`（`solve_newton` 调用）、`total_seconds`（整步/整轮墙钟），全部 `time.perf_counter`。

### 2.5 newton.py 兼容扩展（动机与兼容性）

**动机**：为 T23/大规模问题预留矩阵自由路径并如实记录 Krylov 成本（M-5）；T22 只在明确配置时启用。

**兼容性**：默认 `linear_solver="direct"` 时 `_read_jacobian`/`splu` 路径与错误语义不变；`NewtonOptions`/`NewtonResult` 仅追加带默认值的字段；新增 `telemetry=None` 关键字参数；原 44 项测试逐项通过（§3）。矩阵自由时 `jacobian` 接受 `scipy.sparse.linalg.aslinearoperator` 可接受的一切（稀疏/稠密/`LinearOperator`/带 `shape`+`matvec` 的对象）；可选 `preconditioner` 属性透传 GMRES；GMRES 不收敛/分解失败→`NewtonFailure(phase="linear_solve")`，不回退。评估层在属性读取时抛出的 `NewtonFailure` 由会话补上当前迭代号（T22 适配器标记 `iteration=-1`，由 `newton.py` 归属）。

## 6. 失败路径实测

所有失败均为 `MonolithicNewtonFailure`（`NewtonFailure` 子类），含 `phase`/`iteration`/归一化与原始范数/`diagnostics`；`diagnostics` 为普通映射，可直接进入 `StepTransaction` 失败审计。

| 注入 | phase / iteration | 关键诊断 | 部分计数 |
| --- | --- | --- | --- |
| 试探残差全为非有限（`max_backtracks=4`） | `line_search` / 1 | `trial_residual_norms` 5×`inf`、`trial_merit_norms`、`current_merit`、`minimum_damping`、`full_step_norm` | `linear_solves=1`、`trials=5`、`failed_trials=5`、`failed_steps=1` |
| 组装 Jacobian 第 0 行清零 | `linear_solve` / 1 | `solver="splu"`、`error` 含 "singular"、`nnz` | `linear_solves=1`、`failed_steps=1` |
| 初值 `p_f` 块置 NaN | `evaluate` / 0 | `contract="x0"`、`non_finite_entries=20` | `evaluations=0`、`failed_steps=1` |
| 起始残差注入 NaN | `residual` / 0 | `non_finite_entries=1`、`residual_norm=inf` | `evaluations=1`、`failed_steps=1` |
| `max_iterations=1`、`rtol=1e-12` | `convergence` / 1 | `max_iterations=1`、`threshold` | `newton_iterations=1`、`history` 含 2 条 |
| 推进第 3 步（step 2）线搜索注入（前 2 步已完成） | `line_search` / 1 | `step_index=2`、`counters.steps=2`、`counters.failed_steps=1` | `march_steps` 2 条（含各步 `x`/时间项/计数） |

**基础状态不被污染**：注入失败后 `x0`、`context.base` 的两段历史、参考网格坐标、界面 `H` 全部逐位不变；撤销注入后重新求解与失败前的基线逐位一致（`x`、计数相同）。失败注入只在 264 自由度小问题上执行；真实网格冒烟只覆盖成功路径（§9）。

## 7. 计数、确定性与只读

- 同一步重复运行：`x`、`residual`、残差历史、计数字典逐位/逐项相同；计时仅墙钟不同（不断言相等）。
- 两轮推进（同 dt）或两次同参数推进：`counters` 完全相等、`x` 逐位相同。
- 结果只读：`x`/`residual`/`scales` 冻结、`records` 为元组、映射为 `MappingProxyType`、dataclass 冻结（赋值抛 `FrozenInstanceError`）；输入 `x0` 在求解后被改写不影响结果。
- 计数恒等式：`evaluations = residual+assembled+jvp`；assembled 路由 `assembled_evaluations == jacobian_reads == linear_solves`；`failed_trials = line_search_trials − newton_iterations`（每接受迭代恰一个被接受试探）；推进 `counters` 为各步之和。

| Newton 迭代 | 4 | 4 |
| 解差（缩放 ∞-范数） | — | 4.57e−12 |
| `evaluations`（残差/jvp） | 10（6/4 assembled） | 14（6/8 jvp） |
| `jvp_directions` | 0 | 8 |

预条件由测试显式提供（对接受点组装 Jacobian 做 `splu`，等价精确逆），证明 jvp 通路接线、计数与 GMRES 语义；**适配器不在 jvp 路由静默组装**（`assembled_evaluations=0`）。无预条件时（`gmres_restart=50, gmres_maxiter=1`）得到 `phase="linear_solve"`、`solver="gmres"`、`iterations=50`、`info=1`、`true_residual_norm`，计数 `linear_iterations=50`、`failed_steps=1`——**不回退**到直接法（`assembled_evaluations=0`）。

**真实规模的 Krylov 结论（未决问题）**：在 264 未知量的小问题上，无预条件 GMRES（`restart=50`、4 个循环上限）跑满 200 次内迭代仍未收敛（`info=4`，真残差 0.0637，相对初始 5095 约 1.2e−5，耗时 3.39 s；更宽循环的实验同样停滞），而组装 Jacobian 直接分解瞬时完成；这印证 W2 设计 §4“避免无预条件原始 Krylov”的判断。T22 因此只把 jvp 作为显式预留路径交付，真实 FSI 的场分裂/块对角预条件留待 T23/A0 决策（§11.1）。

## 10. 失败与修正（实现过程中）

1. **BDF2 启动的接受几何层数**：初版推进在每步后把接受几何截断为 `stencil.order` 层；启动步 `order=1` 后一步进入 BDF2，`stencil.order=2` 而几何只剩 1 层，`MonolithicContext` 构造报错。修正：历史保持最近 2 层（与 `BDFHistory` 一致），按当前 `stencil.order` 切片使用。
2. **固定点上下文的接受几何**：验证脚本初版用模板初始几何作为固定点历史几何，网格运动项不抵消，稳态残差出现 2.6e−4 的假偏差；改用由行进解 `d_m` 重建的几何后，稳态残差降到 8.6e−11（阈值 1e−10 内）。该修正只影响验证脚本/测试，不影响推进实现（推进本就按收敛 `d_m` 重建几何）。
3. **近收敛步的容差与线搜索停滞**：更刚（`E=1e6`）或更紧容差（`rtol=1e-10, atol=1e-12`）的实验中，后续步 `‖r0‖` 很小使阈值≈`atol`，直接分解圆整平台（缩放范数 ~1e−11）高于阈值时严格 Armijo 线搜索无下降方向 → `phase="line_search"` 失败。结论：小问题的可认证下限约 1e−10–1e−11；T22 测试用 `rtol=1e-8, atol=1e-10` 并如实记录该平台，未放宽 spec 门槛（M-8 由 T23 复核）。
4. **评估层失败的迭代号**：T22 适配器在属性读取（`residual`/`jacobian`）时抛出失败，此刻不知道 Newton 迭代号；`newton.py` 增加 `_set_failure_iteration`，由会话在捕获点补上正确 `iteration`（适配器标记 `-1`），异常消息同步更新。
5. **诊断字段被外层包装覆盖**：推进包装步级失败时，若沿用 `setdefault` 写入聚合计数/计时，会保留内层的部分计数而不是聚合值；改为显式覆盖（`candidate_id`/`jacobian_mode`/`counters`/`timings`/`step_index`）。
6. **jvp 方向的计数单位**：初版把 `directions` 的元素数当“方向数”（264/direction），修正为向量个数（批大小），`jvp_directions` 现等于 matvec 次数。
7. 测试自身：注入线搜索失败时需按“每步起点”判定试探点（推进后续步的起点不是 `problem.x`）；已修正。

## 11. 未决问题（交下游）

1. **Krylov 与预条件（最重要）**：无预条件 GMRES 在小问题上即不收敛（§8）；真实 FSI 需要场分裂/块对角/物理近似预条件与直接法回退策略（回退需 A0 冻结，不得静默）。当前 `preconditioner` 由调用方提供，其构造成本不计入适配器计数，T23 记录成本时需补充口径。
2. **真实规模性能口径**：h=0.02 组装 Jacobian 单次约 18 s（T21 记录 19.4 s），单步整体法约 78 s；推进至 FSI1 稳态需要大量伪时间步，T23 的比较与成本表应以更粗网格或更省成本的线性路径规划（M-8）。
3. **压力规范（M-3）复核**：本任务冒烟在 `pressure_pin=None` 下组装 Jacobian **非奇异**且 `splu` 成功（出口自然边界固定压力常数），与“整体侧必须用 pin”的担心不符；但两侧一致性仍需 A0 按 M-3 裁决并在 T23 记录（本任务不改变裁决）。
4. **收紧裕度（M-8）**：小问题直接分解的可认证平台约 1e−10–1e−11（§10.3）；T23 的 1e−10 档需要线性求解真残差检查与迭代上限裕度实验。
5. **事务与 CLI 衔接**：`StepPlan` 的整体耦合阶段、`stage/field` 命名、失败记录写入与 CLI 入口未做（A0/A7）；`MonolithicNewtonFailure.diagnostics` 已是普通映射，可直接被 `StepTransaction` 冻结。
6. **原理文档**：`docs/principles/` 不在本任务允许修改的文件清单内，整体 Newton/定常推进的原理说明需由 A0 在后续任务补入（与 T21 的同类事项合并）。
7. **T21 冻结文件复核项**：本任务未发现 T21 缺陷；`iteration=-1` 的适配器约定只依赖 `newton.py`（本任务可写文件）。
