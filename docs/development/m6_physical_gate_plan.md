# M6 分区停止条件与全场残差一致性修复

日期：2026-10-13。范围：第 923 步残差失败的单独修复工作包；不改变材料、ALE 网格权重、BDF、全场残差、物理验收门槛或参考值。原因和原始数据见[第 923 步诊断](../validation/m6_step923_diagnosis.md)。

## 问题与设计

原 IQN 迭代在界面位移间隙达到配置容差时结束，但约 `9.6e-14 m` 的输入与固体输出位移差，在第 923 步的固体动量方程中形成 `1.708e-7` 的全场残差，超过 `1e-7` 门槛。固体单场自身自由残差约 `8.9e-11`，网格质量和连续性均合格。

分区控制器增加可选 `convergence_check(evaluation)`，只在界面间隙已达到原停止容差时执行。它返回真才结束，否则沿原固定/Aitken/IQN 更新继续迭代，不重置本步历史；异常或非布尔返回明确失败。到达最大迭代数仍未满足物理检查时失败；若更新在浮点精度下无法改变界面输入，提前报告停滞。

FSI2 瞬态分区路径用该钩子重算与末端事务相同的六块整体残差 `R(x)`，按原 `max_i |R_i/S_i| ≤ residual_max` 判断。末端事务仍独立重算并检查全残差、连续性和网格质量，作为唯一接受点。独立的固定参考几何分区校验与 FSI1 不自动改用此钩子，其调用方式保持兼容。所有迭代仍只读使用已接受历史，失败不发布候选状态。

## 验收

1. 控制器验证：界面先达标但物理检查拒绝时继续；达到物理门槛才返回；最大迭代、无效检查和浮点停滞明确失败。
2. 瞬态验证：真实小型 FE 在首次物理检查被拒后继续求解，最终与无注入路径同一离散解一致；失败回滚与完整历史断点相关测试通过。
