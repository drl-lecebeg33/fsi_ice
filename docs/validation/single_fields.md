## 流体稳态与力积分

采用仿射三角形上的 P2/P1 Taylor–Hood，自研黏性、压力、连续性、对流项及完整 Newton 切线；7 点积分对五次多项式精确。物理压力约定为 σ=-pI+2με(u)。闭合速度边界算例固定一个压力自由度；具有自然出口的 CFD 算例不额外固定压力。

Poiseuille：域 [0,2]×[0,1]，μ=2，u=(y(1-y)/4,0)，p=2-x。在 4、8、16 三档网格再现二次速度和一次压力，误差达到数值精度。P2/P1 的空间选择参见 [DOLFINx Stokes 官方说明](https://docs.fenicsproject.org/dolfinx/main/python/demos/demo_stokes.html)；方程代码独立实现。

独立网格收敛使用 u=(sin(πx)cos(πy),-cos(πx)sin(πy))、p=sin(πx)sin(πy)，右端直接由解析导数计算。

## 独立时间收敛与历史管理

BDF1/BDF2 使用固定时间步长，BDF2 第一步以 BDF1 启动。固体统一写成 d'=v、M v'+r_int(d)=f，消元后切线为 K+α²M；流体速度惯性项为 αM u+M h。候选状态不修改已接受历史，成功后显式接受；支持快照恢复并拒绝过期或其他历史对象的时间上下文。

为了隔离时间误差，固体使用精确半离散制造状态 d=0.001exp(-t)φ、v=-d 和相应节点载荷；这不是连续空间解析解。流体使用 P2 空间能精确表示的 u=exp(-t)(y(1-y),0)、p=0，右端从连续方程计算。两者分别固定空间网格，在 dt=0.1、0.05、0.025 上运行到 t=1。

| 模块 | 方法 | 最后一次加密的时间阶 |
| --- | --- | --- |
| 固体 | BDF1 | 0.973 |
| 固体 | BDF2 | 1.986 |
| 流体 | BDF1 | 0.986 |
| 流体 | BDF2 | 2.030 |

满足预先规定的一阶 ≥0.9、二阶 ≥1.8。另有已知 ODE 收敛、重复候选求解、失败不接受、跨历史对象拒绝和快照恢复测试。

细长梁的线性系统会发生浮点抵消：通用线性求解保留相对自由残差，必要时以高精度计算残差并迭代修正；当相对残差受抵消影响时，还要求缩放后向误差 ≤1e-14。单场外层继续独立检查物理残差，不能用后向误差代替非线性收敛或基准误差。

动态 CFD 使用完整当前 Newton Jacobian，GMRES 通过复用 LU 分解构成预条件器。它检查当前物理方程的真实线性残差，失败则重新分解；压力变量内部变换为 p/ρ，输出仍为物理压力。已与直接线性求解的瞬态解逐步比较，结果一致。BDF 启动阶次改变时更新预条件器；该实现没有以旧 Jacobian 替代当前 Newton 方程。
